1. ВАЖНО: ПРАВИЛЬНЫЙ ПОРЯДОК ДЕЙСТВИЙ
-------------------------------------

НЕТ: Нельзя сразу индексировать .docx файлы — система работает только с .md

ДА: Правильный порядок:
  1) Конвертировать .docx → .md (через UI: Обработка документов)
  2) Индексировать полученные .md файлы (через UI: Индексация в БД)
  3) Задавать вопросы по индексированным файлам (через UI: Чат с документами)

2. СКАЧИВАНИЕ И ПОДГОТОВКА ФАЙЛОВ
----------------------------------

1) В папке C:\Users\Danil\llmmd-files-folder\ создать подпапку input/
2) Скопировать все .docx файлы в C:\Users\Danil\llmmd-files-folder\input\
3) Убедиться, что файлы действительно .docx (не .pdf, не .txt)

3. ЗАПУСК СИСТЕМЫ
-----------------

ВАЖНО: Запускать в строгой последовательности!

Шаг 1: Включить Docker Desktop
  - Проверить статус "Running" в системном трее

Шаг 2: Запустить LM Studio
  - Открыть LM Studio
  - Загрузить модель gemma-3-1b
  - Включить Local Server (Tools → Developer → Local Server)
  - Проверить URL: http://127.0.0.1:1234 (должен быть активен)

Шаг 3: Запустить llmmd
  - Открыть терминал в папке C:\python-projects\llmmd-lite
  - Выполнить: python llmmd.py
  - Подождать ~2 минуты до полного запуска
  - Открыть браузер: http://127.0.0.1:8501

================================================================================

4. КОНВЕРТАЦИЯ DOCX В MARKDOWN
------------------------------

1) В интерфейсе llmmd (http://127.0.0.1:8501) перейти в раздел "📄 Обработка документов"

2) В поле "Пути к файлам или папкам" указать:
   C:\Users\Danil\llmmd-files-folder\input\

   (УКАЗАТЬ ПУТЬ К ПАПКЕ, НЕ К ОТДЕЛЬНЫМ ФАЙЛАМ!)

3) Убедиться, что:
   ✓ "Плагины MarkItDown" — ВКЛЮЧЕНО
   ✓ "Обработка через LLM" — можно ВЫКЛЮЧИТЬ (для простой конвертации)
   ✓ "Папка результатов": outputs/ (по умолчанию)

4) Нажать "Запустить OCR"

5) Подождать завершения. На выходе в папке outputs/ появятся .md файлы.

================================================================================

5. ИНДЕКСАЦИЯ И ЧАТ
-------------------

После конвертации:

1) Перейти в раздел "🗂️ Индексация в БД"

2) В "Папка для индексации" указать:
   C:\Users\Danil\llmmd-files-folder\outputs\

   (УКАЗАТЬ ПУТЬ К outputs/, ГДЕ ЛЕЖАТ .MD ФАЙЛЫ!)

3) Нажать "Начать индексацию"

4) Подождать завершения (прогресс-бар покажет сколько файлов проиндексировано)

5) Перейти в раздел "💬 Чат с документами"

6) Задать любой вопрос по документам

7) Получить ответ с ссылками на источники

6. ПРОБЛЕМА С 0.2 СЕКУНДНОЙ ИНДЕКСАЦИЕЙ
----------------------------------------

ПРОБЛЕМА: Нажимаешь "Начать индексацию", процесс завершается через 0.2 сек, файлы не создаются.

ПРИЧИНА: Система ищет файлы с расширением .md, а не .docx.

РЕШЕНИЕ:
  1. Сначала ОБЯЗАТЕЛЬНО выполнить конвертацию DOCX→Markdown (раздел "📄 Обработка документов")
  2. Убедиться, что папка C:\Users\Danil\llmmd-files-folder\output\ существует и содержит .md файлы
  3. В индексации указать путь к output/, а не к input/
  4. Если все сделано верно, индексация должна занять несколько секунд (а не 0.2 сек)

================================================================================

ПРОВЕРКА ПРОЦЕССА
-----------------

1) После конвертации проверить: C:\Users\Danil\llmmd-files-folder\output\*.md

2) После индексации проверить RAG API: http://127.0.0.1:8765/health
   Должно вернуть: {"ok": true, "hybrid": true, ...}

3) Статус индексации: http://127.0.0.1:8765/v1/status
   В разделе "index_job" должно быть files_done > 0

4) Если файлов 0 — значит, конвертация не удалась. Повторить шаг 4.

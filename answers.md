Ответы на вопросы по запуску RAG-системы llmmd:

Вопрос 1. Как нужно запускать систему для полноценной работы?

Ответ:
Для полноценной работы системы необходимо последовательно запустить все компоненты:

1. Запустить Docker Desktop
   - Это требуется для запуска Qdrant (векторная база данных)

2. Запустить LM Studio
   - Запустить приложение LM Studio
   - Перейти в настройки (Setting → левый нижний угол)
   - В разделе «Local Model API» включить «Local API Server»

3. Запустить локальную модель в LM Studio
   - Скачать и установить локальную LLM-модель через LM Studio (например, Google Gemma 3 1B)
   - Загрузить модель для работы

4. Запустить RAG-систему
   - Открыть терминал/PowerShell
   - Перейти в папку проекта: cd C:\python-projects\llmmd-lite
   - Выполнить команду: python llmmd.py
   - Дождаться завершения запуска (около 2 минут)

5. Открыть веб-интерфейс
   - Через браузер перейти по адресу: http://localhost:8765

Вопрос 2. Правильный ли порядок запуска:

1. Запустить Docker Desktop ✓
2. Запустить LM Studio ✓
3. Запустить Local API Server в LM Studio ✓
4. Открыть терминал ✓
5. Зайти в папку проекта llmmd-lite ✓
6. Запустить командой python llmmd.py ✓
7. Подождать 2 минуты ✓
8. Зайти в веб-интерфейс через браузер по адресу http://localhost:8765 ✓
9. Начать работу ✓

Ответ: Да, порядок запуска правильный и соответствует инструкции из документации.

Дополнительная информация:

- После запуска системы можно индексировать документы через веб-интерфейс
- В разделе «Индексация» нужно указать путь к папке с .md файлами
- Для полноценной работы чата необходима локальная LLM-модель, загруженная в LM Studio
- По умолчанию система использует модель эмбеддингов для анализа текста и LLM для генерации ответов
- Система поддерживает работу с файлами docx и pdf (автоматически конвертирует в markdown)

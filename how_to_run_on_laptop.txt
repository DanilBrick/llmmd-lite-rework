LLMMD LITE — ИНСТРУКЦИЯ ПО ЗАПУСКУ И РАБОТЕ НА НОУТБУКЕ
================================================================================

ПРЕРЕКВИЗИТЫ
-------------
1. Docker Desktop installed and running
2. LM Studio installed with gemma-3-1b model loaded
3. LM Studio Local Server enabled (Tools → Developer → Local Server)
4. Python 3.10+ with required dependencies

================================================================================

ЭТАП 0: ПЕРВОНАЧАЛЬНАЯ НАСТРОЙКА (ОДИН РАЗ)
------------------------------------------
В терминале (папка проекта):
  python llmmd.py setup

Это установит все необходимые Python-зависимости.

================================================================================

ЭТАП 1: ЗАПУСК СЕРВИСОВ (Каждый Раз)
---------------------------------

ВАЖНО: Запускать в строгой последовательности!

1) Запустить Docker Desktop (проверить, что статус "Running")

2) Запустить LM Studio:
   - Открыть LM Studio
   - Загрузить модель gemma-3-1b (или другую по желанию)
   - Включить Local Server (Tools → Developer → Local Server)
   - Убедиться, что сервер запущен на http://127.0.0.1:1234

3) Запустить приложение llmmd:
   В терминале (в папке проекта):
     python llmmd.py

   Эта команда запустит:
   - RAG API на http://127.0.0.1:8765
   - Streamlit UI на http://127.0.0.1:8501

================================================================================

ЭТАП 2: РАБОТА С ДОКУМЕНТАМИ

A) КОНВЕРТАЦИЯ DOCX В MARKDOWN
-----------------------------
Открыть UI в браузере:
  http://127.0.0.1:8501

Перейти в раздел "📄 Обработка документов" (OCR/Document Processing):

1) В поле "Пути к файлам или папкам" указать путь:
   - Для одной папки: C:\Users\Danil\llmmd-files-folder\
   - Для конкретных файлов: C:\Users\Danil\llmmd-files-folder\document.docx
   - Можно использовать маски: C:\Users\Danil\llmmd-files-folder\*.docx

2) Убедиться в настройках:
   ✓ "Плагины MarkItDown" — включено (для поддержки DOCX)
   ✓ "Обработка через LLM" — можно выключить для базовой конвертации
   ✓ Папка результатов: по умолчанию outputs/

3) Нажать "Запустить OCR"

4) Подождать завершения. После окончания в папке outputs/ появятся:
   - .md файлы (markdown-версии ваших документов)
   - Папки с изображениями (_assets)

B) ИНДЕКСАЦИЯ В ВЕКТОРНУЮ БАЗУ
-------------------------------
После конвертации перейти в раздел "🗂️ Индексация в БД":

1) Проверить "Папка для индексации":
   Должна указывать на outputs/ или ту папку, где лежат .md файлы

2) Нажать "Начать индексацию"

3) Подождать завершения (в UI будет прогресс-бар)

C) ЧАТ С ДОКУМЕНТАМИ
--------------------
Перейти в раздел "💬 Чат с документами":

1) В поле "Ваш вопрос:" ввести вопрос по документам
2) Нажать "Отправить"
3) Получить ответ с ссылками на источники

================================================================================

ЭТАП 3: ПРОБЛЕМЫ И РЕШЕНИЯ

PROBLEM: Индексация завершается через 0.2 секунды, файлы не создаются
SOLUTION: 
  1. Убедиться, что в папке C:\Users\Danil\llmmd-files-folder\ лежат файлы .docx
  2. В "Пути к файлам или папкам" указать: C:\Users\Danil\llmmd-files-folder\
  3. Сначала выполнить конвертацию DOCX→Markdown, затем индексировать

PROBLEM: Qdrant не запускается
SOLUTION: Убедиться, что Docker Desktop работает. Запустить вручную:
  python llmmd.py qdrant up

PROBLEM: LM Studio не подключается
SOLUTION: Проверить, что Local Server включен и модель загружена.
  URL должен быть http://127.0.0.1:1234/v1

PROBLEM: Конвертация DOCX не работает
SOLUTION: Попробовать выключить "Плагины MarkItDown" или использовать PDF вместо DOCX

PROBLEM: Нет ответов в чате
SOLUTION: 1) Убедиться, что документы проиндексированы
  2) Проверить статус RAG API на http://127.0.0.1:8765/health
  3) Убедиться, что модель загружена в LM Studio

PROBLEM: Как остановить сервисы
SOLUTION: В терминале нажать Ctrl+C (остановит RAG и UI, Qdrant останется)

PROBLEM: Как удалить индекс и начать заново
SOLUTION: В разделе "🛠️ Сервисы" → Qdrant → нажать "Down", потом "Up" заново
  ИЛИ использовать галочку "recreate collection" при индексации
  Затем переиндексировать документы.

КОМАНДЫ ТЕРМИНАЛА
-----------------

python llmmd.py setup              — Установка зависимостей
python llmmd.py                    — Запуск полного стека (RAG + UI)
python llmmd.py run                — То же самое
python llmmd.py doctor             — Diagnostics
python llmmd.py info               — Информация о проекте

python llmmd.py qdrant up          — Запустить Qdrant в Docker
python llmmd.py qdrant down        — Остановить Qdrant
python llmmd.py qdrant status      — Статус Qdrant

python llmmd.py rag                — Запустить только RAG API
python llmmd.py web                — Запустить только UI

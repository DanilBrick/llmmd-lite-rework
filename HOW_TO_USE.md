# llmmd lite Rework - инструкции по запуску и использованию

В данной инструкции содержатся алгоритмы правильного запуска и остановки всех компонентов пайплайна, приведено информация по использованию. 

Интсрукции по установке всех необходимых компонентов и самого проекта приведены в файле **INSTALL.md**. 

## Алгоритм запуска llmmd lite Rework и компонентов

Примечание: для правильного запуска требуется выполнять все шаги по порядку.

1. Запустите Docker Descktop (в трее должен появится значок);
2. Запустите LM Studio;
3. В LM Studio зайдите в settings;
4. Из списка слева выберте пункт Local Model API;
5. В вкладке "Local Model API" включите "Local API server" (в поле "Base URL" должен появится адрес);
6. Зайдите в терминал;
7. Перейдите в папку проекта - выполните команду `cd C:\python-projects\llmmd-lite-rework` (пример);
8. Запустите проект - выполните команду `python llmmd.py`;
9. Дождитесь окончания загрузки: она займет пару минут, а в терминале появится строка `INFO:    Unicorn running on http://127.0.0.1:8765 (Press CTRL+C to quit)`;
10. Откройте бразуер и перейдите в веб-интерфейс по адресу `http://127.0.0.1:8765` или `http://localhost:8765`;

## Алгоритм отключения llmmd lite Rework и компонентов

Примечание: для правильного отключения требуется выполнять все шаги по порядку.

1. Нажмите Ctrl + C в терминале, в котором запущена llmmd-lite rework;
2. Откройте новую вкладку терминала;
3. В новом терминале перейдите в папку проекта, например, выполнив команду `cd C:\python-projects\llmmd-lite-rework`;
4. В том же новом терминале выполните команду `docker-compose -f rag_service\docker-compose.qdrant.yml down` - так будут корректно отключены контейнеры qdrant;
5. Закройте саму программу Docker Desktop;
6. В системном трее найдите иконку Docker, нажмите правой кнопкой мыши и выберите "Quit Docker Desktop";
7. зайдите в LM Studio;
8. В LM Studio перейдите в settings, далее Local Model API - отключите Local API Server;
9. В системном трее найдите значок Bionic, нажмите правой кнопкой мыши, выберите "Quit Bionic".

## Индексирование файлов Markdown

Для того, чтобы локальная модель могла формировать ответы на основе информации из файлов, их необходимо проиндексировать. 

1. Запустите llmmd и сопутствующие компоненты по инструкции;
2. Укажите папку с файлами формата .md, которые хотите проиндексировать. В веб интерфейсе укажите её в поле для заполнения "Корпус по умолчанию (каталог)" (пример: `C:\Users\Danil\llmmd-files-folder\input`);
3. Откройте выпадающее менб "Запуск индексации (Post /v1/index)";
4. Если вы индексируете файлы впервые в рамках текущей сессии, то оставьте галочку "wait (дождаться конца)". Если вы повторно индексируете файлы, добавьте галочку "recreate_collection";
5. Запустите процесс индексации, нажав кнопку "Запустить";

В области "Индексация" будут отображаться статус и другая информация по процессу. Во время штатного исполнения будет обозначение фазы "Running", в строчке "Текущий файл" будет написано имя индексируемого файла. Индексация может занять разное время в зависимости от характеристик компьютера и размера обрабатываемых файлов.

По завершению индексации в строке "Фаза" будет указано "Complete". После этого можно переходит в чат с локальной LLM для получения нужной информции из обработанных данных.

## Работа с чатом локальной языковой модели (LLM)

Инструкция по работе с чатом локальной LLM:

1. Нажмите кнопку "Откырть чат" в верхней части веб-интерфейса llmmd;
2. Перейдите в нижнюю часть страницы, откройте выпадающую область "Чат с документами (RAG)";
3. В поле "Ваш запрос" напишите запрос для LLM;
4. Для отправки запроса нажмите кнопку "Отправить".

Время ответа зависит от характеристик компьютера. Качество ответа на запрос зависит от модели: чем больше параметров, тем лучше. Для более качественных ответов, опять же, потребуется более производительный компьютер.

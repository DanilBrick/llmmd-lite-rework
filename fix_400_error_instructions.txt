ПРОБЛЕМА
---------
Ошибка: "Client error '400 Bad Request' for url 'http://localhost:1234/v1/chat/completions'"

ПРИЧИНА
-------
1. В настройках был указан неправильный параметр semantic_chunk_model:
   - Было: "nomic-embed-text-v1.5-GGUF" (модель эмбеддингов)
   - Это не LLM-модель, она не поддерживает /chat/completions API

2. LM Studio вернула 400 Bad Request, когда код попытался использовать
   модель эмбеддингов для чанкинга через /chat/completions

ИСПРАВЛЕНИЕ В КОДЕ
------------------
Уже выполнены изменения в 3 файлах:

1) rag_service/semantic_chunking.py:
   - Добавлен список _STOP_MODELS с запрещенными моделями эмбеддингов
   - Добавлена валидация модели перед HTTP-запросом
   - В функции split_for_index() добавлена проверка модели

2) rag_service/main.py:
   - Добавлена проверка semantic_chunk_model при запуске RAG API
   - Добавлена проверка lm_model в _rag_answer_with_provider()

3) rag_service/ui_settings.json:
   - semantic_chunk_model: google/gemma-3-1b (было: nomic-embed-text-v1.5-GGUF)
   - lm_studio_rag_model: google/gemma-3-1b (было: nomic-embeded-text-v1.5-GGUF)

ЧТО НУЖНО СДЕЛАТЬ ПОЛЬЗОВАТЕЛЮ
-------------------------------

1) ПЕРЕЗАПУСТИТЬ LLMMD:
   - В терминале нажать Ctrl+C для остановки
   - Выполнить: python llmmd.py
   - Дождаться полного запуска (~2 минуты)

2) ПРОВЕРИТЬ ЛОГИ ПРИ ЗАПУСКЕ:
   - Если в логах есть сообщение об ошибке про semantic_chunk_model,
     значит модель все еще не подходит
   - Правильная модель: google/gemma-3-1b

3) В LM STUDIO УБЕДИТЬСЯ, ЧТО:
   - Tools → Developer → Local Server включен
   - Base URL: http://localhost:1234/v1
   - В разделе "Local Models" загружена модель "google/gemma-3-1b"

4) ПРОВЕРИТЬ СПИСОК МОДЕЛЕЙ:
   - Открыть в браузере: http://localhost:1234/v1/models
   - Должно быть что-то вроде:
     {
       "data": [
         { "id": "google/gemma-3-1b", ... },
         { "id": "text-embedding-nomic-embed-text-v1.5@q8_0", ... }
       ]
     }

5) ПОВТОРИТЬ ИНДЕКСАЦИЮ:
   - Раздел "🗂️ Индексация в БД"
   - "Папка для индексации": C:\Users\Danil\llmmd-files-folder\input\
   - Нажать "Начать индексацию"

6) АЛЬТЕРНАТИВА: ОТКЛЮЧИТЬ SEMANTIC ЧАНКИНГ:
   - Раздел "⚙️ Настройки RAG"
   - "Режим чанкинга": выбрать "heading" вместо "heading_semantic"
   - Это отключит использование LM Studio для чанкинга

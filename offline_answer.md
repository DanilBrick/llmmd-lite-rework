Ответ на вопрос о работе без интернета:

Да, система llmmd может работать полностью локально без подключения к интернету, но это требует определенных условий.

Условия для полностью локальной работы:

1. **Qdrant** — работает локально в Docker-контейнере (http://localhost:6333)

2. **Эмбеддинг-модели** — загружаются из HuggingFace при первом запуске, затем хранятся локально:
   - Dense модель: `intfloat/multilingual-e5-large` (SentenceTransformer)
   - Sparse модель: `Qdrant/bm25` (fastembed) — опционально, для гибридного поиска
   - Модели хранятся в кэше пользователя (обычно ~/.cache/huggingface)

3. **LLM для генерации ответов** — только через LM Studio (локальная модель):
   - Система поддерживает три провайдера: lm_studio, openai, anthropic
   - Для локальной работы используется только **lm_studio**
   - OpenAI и Anthropic требуют доступа к облачным API (интернет обязателен)

4. **Чанкинг (разбиение документов)** — может использовать LM Studio для semantic chunking:
   - В режиме "heading" — только деление по заголовкам (локально, без LLM)
   - В режиме "semantic" — требует локальную LLM через LM Studio
   - В режиме "heading_semantic" — комбинированный подход

Рекомендации для полностью локальной работы:

- Использовать режим чанкинга "heading" (по умолчанию) — не требует LLM при индексации
- Загрузить локальную модель через LM Studio для генерации ответов (например, Google Gemma 3 1B)
- Отключить гибридный поиск, если нужна максимальная локальность
- Убедиться, что все модели загружены и кэшированы при первом запуске (требует интернет)

Когда интернет нужен:
- При первом запуске для загрузки эмбеддинг-моделей из HuggingFace
- При использовании облачных провайдеров (OpenAI, Anthropic)
- При semantic chunking с локальной LLM (если модель не загружена заранее)

Заключение: Система поддерживает полностью локальную работу через LM Studio, но при первом запуске потребуется интернет для загрузки моделей. После этого все операции (индексация, поиск, генерация ответов) могут выполняться без интернета.
